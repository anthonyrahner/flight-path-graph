# Flight Path Graph (Java, Data Structures)

A Java project representing flight connections between cities using directed graphs with adjacency lists.  
Designed to efficiently explore network connectivity and simulate flight routes between locations.

## 🧠 Features
- Represents cities as nodes and flights as directed edges
- Uses adjacency lists for efficient storage and traversal
- Supports adding edges and querying connectivity
- Demonstrates graph data structures and traversal algorithms

## ⚙️ Technical Overview
- **Language:** Java  
- **Concepts Used:** Graphs, Adjacency Lists, Object-Oriented Programming  
- **Topics:** Data Structures, Graph Traversal, Network Representation
